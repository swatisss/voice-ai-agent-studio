# What it is

A pre-authorisation code (for example PA-500812) confirms we have agreed to cover a specific consultation, test or treatment. Give it to the specialist or hospital when you book: they **bill us directly**, so you do not pay and claim back. You pay only any excess and any shortfall.

# Validity

A code is usually valid for **90 days** and covers only what it says. Further tests or a different treatment need a new pre-authorisation.

# Surgery

For surgery we need the specialist's **procedure code and fee estimate**. Until they send it, the pre-authorisation is **pending**; we usually decide within 2 working days. Do not book surgery until it is approved.

# Moratorium members

Before the first claim for a condition, moratorium members complete a short pre-treatment form confirming the condition is new.
