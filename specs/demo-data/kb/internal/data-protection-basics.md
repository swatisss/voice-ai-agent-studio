# Overview

## Rules

* Verify identity before disclosing any member information.
* Share only the minimum necessary to answer the request.
* Never put health details in email subject lines or text messages.
* Tell callers when a call is recorded.

## Breaches

Report any suspected breach to the Privacy Office, ext. 4700, within **24 hours**.
