# Overview

This business unit starts empty so you can see how a team builds an agent from scratch.

1. Create a **persona** (voice, greeting, style).
2. Add **knowledge** (paste text, upload a file or an OKF bundle, or import a URL).
3. Define **tools** that call your business API, and **skills** that describe procedures.
4. Create an **agent**, attach the pieces, set its **voice** options, and **publish** it.
5. Try it from **Test call**.
