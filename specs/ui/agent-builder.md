# Agents list (`/agents/`)

Cards: name, description, **mode badge** (Inbound / Outbound / Internal), published version (or "Not published"), updated time; actions **Open**, **Test**. Button **New agent** (modal: name, description) creates an agent with default persona/policy and opens it; where the business unit allows realtime, the new agent starts on *Realtime speech-to-speech* with *Hindi* ticked (LANG-11).

# Builder (`/agents/edit/?id=…`)

Header: agent name, version badge (`v3` / "Draft changes" when draft differs from published), buttons **Save draft**, **Publish** (modal with change note; shows validation errors from the API), **Run tests** (saves the draft if it has unsaved changes, then starts a test-suite run on the draft, [/architecture/test-suites.md](/architecture/test-suites.md); shows progress "Testing 7 of 18" and then "5 of 6 scenarios passed every run" linking to the run; never blocks Publish; disabled with a note when the agent has no scenarios), **Test call** (opens `/test-call/?agent=…`).

Tabs:

| Tab | Content |
|---|---|
| Overview | Name, description (note: "Used to route callers to this agent; published with the agent"), **Route callers to this agent** switch (`routable`, inbound and internal agents only) and **Introduction when a caller is routed here** (`handoff_intro`), realtime model select (`GET /api/models`, "Default (role setting)" first), counts of docs/tools/skills; a warning when an attached tool requires verification but no attached tool verifies: "Some tools need a verified caller, but this agent has no verification tool, so they will never run." (computed from the draft, updated as tools are ticked, never blocks Save draft or Publish; [/architecture/caller-verification.md](/architecture/caller-verification.md)); **mode** select (Inbound / Outbound / Internal) and, for outbound agents, the **targets URL** |
| Use cases | The agent's use cases ([/product/use-cases.md](/product/use-cases.md)) as rows: title, summary, sample phrases (chips); **Add use case** and row **Edit** open a form (title, summary, category, channels, sample phrases one per line, 1–20); **Delete** asks for confirmation. Changes save at once (not with the draft) with the note "Use cases update routing right away; they are not part of a version". Below: the agent's **routing profile** status (*Up to date*, *Updating…*, *Failed* with the error) and its generated example requests (`GET /api/agents/{id}/capability`) ([/architecture/capability-catalog.md](/architecture/capability-catalog.md)). |
| Persona | Choose a **library persona** (select, with a read-only summary and a link to the Personas page). Agents without a library persona edit the inline persona fields (name, voice, speed, greeting, disclosure, outbound opening, style) as before. |
| Policy | editable lists (rules, escalate when, never), max turns, handoff and holding messages, safety screen toggle, voice filler toggle |
| Voice | **Voice pipeline**: two selectable cards, *Cascade* ("speech-to-text, the agent brain, text-to-speech; the default") and *Realtime speech-to-speech* ("one OpenAI model listens and speaks; lower delay, higher cost"; disabled with the note "Not enabled for this business unit - turn it on in Settings" and a link to `/settings/` when the tenant's `allowed_pipelines` lacks `realtime`); with Realtime, a **Realtime voice** select (voices from `GET /api/models`) replaces the persona voice, and the evaluator and extra-wait controls below are disabled with a note "The realtime service decides when the caller has finished". **Transfer to** (phone number in international format or `sip:` URI, optional): where a live phone call is redirected after a hand-off. **Turn detection**: two selectable cards, *Normal detection* ("ends the turn after a silence") and *Semantic detection* ("also understands whether the caller has finished"); sliders for silence threshold (200–2000 ms) and, in semantic mode, extra wait (0–4000 ms); evaluator choice (*Local rules* / *LLM check*, with a note that it adds a small model call); *Allow the caller to interrupt* toggle. **Languages**: *English* (always on, disabled) and a *Hindi* checkbox with the hint "Callers can speak Hindi, English or both and switch at any time. Needs Realtime speech-to-speech."; with Hindi ticked and *Cascade* selected, an inline warning "Hindi needs Realtime speech-to-speech - switch the voice pipeline to publish" is shown and Publish shows the API's `language_needs_realtime` message. Values save with the draft and are versioned on publish. |
| Knowledge | Tenant docs with checkboxes (attached to this agent) + status badges; add via **Paste text**, **Upload** (.md/.txt/.pdf/.zip OKF), **From URL** (dialog: URL, **What to index** *Just this page* / *This site section* with **Up to N pages** (default 25, at most 100), **Keep in sync** *Off* / *Daily* / *Weekly*; creates a website source that is ticked for this agent at once; [/architecture/knowledge.md](/architecture/knowledge.md)); website sources are rows of their own: title, start URL, status (*Indexing… 7 of 19 pages*, *Ready*, *Partial: 25 of 40 pages*, *Failed* with the reason), page count, "synced 5 min ago", **Sync now**, expandable to their pages (title, link, chunk count; skipped pages with the reason); doc preview drawer showing chunks; **Test search** box showing scored results (with the page link for website results) or "No answer" |
| Tools | Tenant tools with checkboxes; create/edit form: name, description, method, URL, parameters (JSON editor with validation), requires verification, is verification, timeout |
| Skills | Tenant skills with checkboxes; create/edit form: name, description, instructions (textarea), required tools (multi-select), escalate when |
| Memory | **Remember callers between calls** toggle (on by default); **Remember things like…** and **Never remember…** text boxes, pre-filled with the defaults and a note "Health details, payment details and ID numbers are never remembered, whatever you write here"; **Forget call summaries after** (days) and **Forget facts after** (days); **Trust verified caller ID (demo only)** toggle with a note that it skips the date of birth only for read-only lookups on US calls with full carrier attestation ([/architecture/agent-memory.md](/architecture/agent-memory.md), [/architecture/caller-verification.md](/architecture/caller-verification.md)) |

| Versions | Table of versions (number, change note, source proposal link, date) |

Unsaved changes show a sticky bar "Unsaved changes — Save draft". Navigating away with unsaved changes asks for confirmation.

# Acceptance

- **UI-42** — Given the Memory tab of a draft agent, when memory is switched off, the retention is set to 30 and 180 days and Publish is clicked, then the new version's snapshot holds those values; a retention outside the allowed range shows the API's validation error; a new agent shows the toggle on and the default texts.
- **UI-49** — Given the Evaluation tab of a draft agent, when a Never item is added on the Policy tab and the draft is saved, then the Evaluation tab lists a new hard-gate check *From your policy* with that text; adding a custom check and publishing puts it in the new version's snapshot; an eleventh custom check shows the API's validation error.
- **UI-53** — Given a draft with unsaved changes, when **Run tests** is clicked, then the draft is saved, a run on the draft starts, the header shows its progress and then the pass^k result linking to the run, and **Publish** stays enabled throughout.
- **UI-05** — Given an agent with a skill requiring a tool that is not attached, when Publish is clicked, then the modal shows the API error naming the missing tool and no version is created.
- **UI-06** — Given the Knowledge tab, when a `.zip` OKF bundle is uploaded, then each imported doc appears in the list with source "OKF".
- **UI-26** — Given the Agents list and an agent's Overview tab, then each agent shows its mode, and changing the mode and targets URL saves with the draft and is part of the published version.
- **UI-38** — Given the Voice tab of a draft agent, when *Realtime speech-to-speech* is selected, a realtime voice is chosen and a transfer number `+15557654321` is entered, then after Save draft and Publish the new version's snapshot contains `voice.pipeline: "realtime"`, that voice and `telephony.transfer_to`; an invalid number such as `0123` shows the API's validation error and nothing is saved; and the evaluator and extra-wait controls are disabled while Realtime is selected.
- **UI-41** — Given a business unit that does not allow realtime, when the Voice tab opens, then the *Realtime speech-to-speech* card is disabled with the Settings note and link and *Cascade* stays selected; after realtime is allowed in Settings, the card can be selected.
- **UI-22** — Given the Voice tab, when *Semantic detection* is selected, then the extra-wait and evaluator controls appear (hidden in *Normal detection*), and after Save draft and Publish the new version's snapshot contains the chosen values.
- **UI-07** — Given the Knowledge tab, when "Test search" is run with an unrelated query, then the panel shows "No answer — the agent would offer a specialist".
- **UI-65** — Given an agent whose attached tools include one with *requires verification* and none with *is verification*, when the builder opens, then the Overview tab shows the warning "Some tools need a verified caller, but this agent has no verification tool, so they will never run." and Save draft and Publish still work; attaching a verification tool removes the warning without a reload.
- **UI-66** — Given the Knowledge tab, when **From URL** is used with *This site section* on the fixture site, then the dialog closes at once, a source row shows *Indexing…* with a rising page count and then *Ready · 4 pages*, the source is ticked for the agent, Test search for a fact on the second page shows that page's link, and **Sync now** updates "synced … ago".
- **UI-73** — Given the Voice tab of an agent on *Cascade*, when *Hindi* is ticked, then the warning appears and publishing shows the `language_needs_realtime` message; after switching to *Realtime speech-to-speech*, the warning disappears, and after saving and reloading *Hindi* is still ticked.
- **UI-59** — Given the Use cases tab of a published agent, when a use case with two sample phrases is added, then it is listed at once, the routing profile shows *Updating…* and then *Up to date* with generated examples, and a duplicate title shows the API's error; switching *Route callers to this agent* off and publishing removes the agent's routing profile.
